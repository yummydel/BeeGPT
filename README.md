# 🐝 BeeGPT

**A cozy local bee companion with memory, voice, vision, personalities, stories, plants, characters, and its own Hive Hub.**

BeeGPT is a playful local chat app built with **Flask + Ollama**.

It runs on your own computer, keeps chats and memories locally, and includes a bunch of bee-themed features that make it feel more like a little personal world than a normal chatbot.

# ✨ Features

## 💬 Chat

BeeGPT includes:

- streaming responses
- typing-style responses
- chat history
- generated chat titles
- search
- delete chats
- edit last message
- regenerate response
- copy responses
- save chats as text files
- timestamps

---

## 🧠 Long-Term Memory

BeeGPT can remember useful things between conversations.

Examples:

- favorite plants
- hobbies
- preferences
- story details
- recurring projects
- character information
- how you like BeeGPT to behave

You can also manually save memories with:

```text
